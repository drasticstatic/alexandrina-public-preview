A small, careful knowledge engine for communities. Point it at your own materials, and members get answers in your own words, with the page they came from, plus helpdesks that turn requests into tracked work. When it doesn't know, it says so.

One engine, many libraries

Every community keeps its own shelf

Each community is a tenant: its own sources, voice, crisis text, desks and visibility rules. The engine never mixes shelves, and committee-only drafts never leave committee. That's enforced in code, with tests that try to leak them.

Sourced or silent

Answers cite their pages. No match means an honest “not in our materials.”

Safety before AI

Crisis, dosing and sourcing are caught by plain rules before any model runs.

An honest model chain

Claude when funded, then NVIDIA NIM. If all fail: “unavailable”, the closest pages and a ticket.

Private by design

No content logging. Ticket requesters are stored as a keyed hash, never an ID.

Eight steps, three honest exits

Configuration, not code

A new community is a folder

Persona, sources, crisis text, retrieval thresholds and helpdesks live in one YAML file beside the community's own Markdown and PDFs. Deployments snapshot the engine instead of forking its history, so private origins stay private.

Roadmap

Where it's headed

Pilot build, October 2026. The engine source is private for now; this page is its public window.

  • Discord surface: slash commands, a chat panel, private ticket threads, archive and reopen
  • Helpdesks → GitHub: problems become Issues, ideas become Discussions
  • FAQ answer cache: instant replies that survive model outages
  • Citations that land on the sentence: text-fragment links
  • Web portals with password-free magic-link sign-in
  • Research lanes via Firecrawl, kept apart from community shelves
  • More tenants: O-R-G next, with its community's blessing
